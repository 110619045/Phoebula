Eyes

Draw two large circles for the eyes, then draw two smaller circles for the pupils. The pupils follow the mouse position.


    function draw(){
        let eyeX = (mouseX-200)/70;
        let eyeY = (mouseY-240)/70;

        circle(155,240,30);
        circle(245,240,30);
        fill(0);
      
        circle(155+eyeX,240+eyeY,10);
        circle(245+eyeX,240+eyeY,10);
        fill(255);
    }

Hair

First, set the starting coordinates of the first strand of hair and its growth direction. Then, use frameCount to control how the hair grows over time. The line() function is used to draw the hair. When y2 is above 100 and below 205, the hair grows upward and becomes longer. When y2 reaches 100, the direction reverses and the hair starts becoming shorter.


    let yOriginal = 205;
    let xOriginal = 100;
    let yNow = yOriginal;
    let directionY = -1;

    function draw(){
        let length = frameCount%5;
        yNow += length * directionY;

        if (yNow <= 100) {
            yNow = 100;
            directionY = 1;
        }
        else if (yNow >= 205) {
            yNow = 205;
            directionY = -1;
        }

        for(let i=0; i<=200; i+=10){
            line(xOriginal+i, yOriginal, xOriginal+i, yNow);
        }
    }
