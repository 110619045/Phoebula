Lab: Tone Output Using An Arduino

Use Serial.println(sensorValue); and the Serial Plotter to find your sensor's range.

  • constrain() - limits a value to a specific range.
  • map() - converts a value from one range to another.
frequency = constrain(frequency, 10, 1000); // do this after the map() command

Without the tone()

By repeatedly switching the speaker pin from HIGH -> LOW -> HIGH -> LOW, sound can be produced. 


void setup() {
  Serial.begin(9600);
  pinMode(8, OUTPUT);
}

void loop() {
  int analogValue = analogRead(A0);
  Serial.println(analogValue);

  float frequency = map(analogValue, -200, 1200, 100, 1000);
  frequency = constrain(frequency, 100, 1000);

  makeTone(frequency);
}

void makeTone(float frequency) {
  int period = (1 / frequency) * 1000000;

  digitalWrite(8, HIGH);
  delayMicroseconds(period / 2);

  digitalWrite(8, LOW);
  delayMicroseconds(period / 2);
}
